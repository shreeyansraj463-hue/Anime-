THE BOY WHO WANTED TO UNDERSTAND THE UNIVERSE
Cinematic anime website prototype

HOW TO RUN
1. Extract the complete ZIP file.
2. Keep index.html and the assets folder together.
3. Open index.html in a modern browser.

The storyboard image has been separated into ten independent scene backgrounds.
The site uses scroll-controlled crossfades, slow camera push-ins, moving atmospheric
cloud overlays, dust/star particles, and responsive typography.

NOTE
The source artwork is a storyboard collage, so some individual crops contain small
lettering or panel edges from the original image. The character's hair is part of
the still illustration, not a separately rigged animation layer. For genuinely
independent hair, clothing, and facial animation, the character must be illustrated
as separate layers or rendered as a 2D/3D animated asset.
